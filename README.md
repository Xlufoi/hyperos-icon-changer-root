# HyperOS Icon Changer (Root)

Инструмент кастомизации значков приложений для HyperOS (Xiaomi / Redmi / POCO) с прямой установкой через Root в обход удалённого или неработающего приложения «Темы» (`com.android.thememanager`).

## Возможности
- **8 классических форм AOSP:**
  - Круг (Circle)
  - Сквиркл (Squircle)
  - Скруглённый квадрат (Rounded Square)
  - Капля (Teardrop)
  - Шестиугольник (Hexagon)
  - Восьмиугольник (Octagon)
  - Цилиндр (Pebble)
  - Квадрат (Square)
- **Стили картинки значка:**
  - **Оригинальные цвета (Стоковые логотипы):** сохраняет оригинальные логотипы приложений без искажений и артефактов (Звонки, Галерея, игры, мессенджеры).
  - **Themed Monet (AOSP Монохром):** адаптивный Material You монохром в тонах Monet.
  - **Themed Черно-белый:** чистый белый силуэт.
- **Отдельная настройка прозрачности подложки (0% — 100%):**
  - Плавная регулировка ползунком: от полностью прозрачной до плотной подложки.
- **Отдельная настройка заполнения / масштаба значка (30% — 100%):**
  - Регулируйте размер логотипа внутри контейнера по своему вкусу.
- **Цветовые палитры:**
  - Monet (динамически берет цвет из текущих системных обоев)
  - Pure Black (глубокий черный для AMOLED)
- **100% покрытие всех приложений:**
  - Автоматически находит абсолютно все установленные приложения через `QUERY_ALL_PACKAGES` и генерирует значки для каждого из них.
- **Глубокая очистка кэша:**
  - Очищает кэши и базы данных как POCO Launcher (`com.mi.android.globallauncher`), так и HyperOS Launcher (`com.miui.home`).

## Установка и использование
1. Скачайте и установите **[HyperOS-Icon-Changer.apk](https://github.com/Xlufoi/hyperos-icon-changer-root/releases/latest/download/HyperOS-Icon-Changer.apk)**.
2. В приложении настройте:
   - Форму значков
   - Стиль значков (Оригинальные цвета или Themed Monet)
   - Цвет подложки (Monet или Черный)
   - Ползунок прозрачности (например, 70%)
   - Ползунок заполнения (например, 65%)
3. Оцените результат в живом предпросмотре.
4. Нажмите **«Применить в HyperOS (Root / 1 тап)»** и предоставьте Root-доступ.
5. Лаунчер автоматически перезапустится с новыми значками!
